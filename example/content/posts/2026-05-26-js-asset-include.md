# External JS and CSS Asset Includes

This page demonstrates loading external JavaScript and CSS files via the `INCLUDES` directive. The directive for this page is:

```markdown
[INCLUDES]: # (H, F, /js/demo.js)
```

This injects `<script src="/js/demo.js"></script>` before `</body>`.

## How It Works

Any value in `INCLUDES` that contains a `.` is treated as an asset file:

| Extension | Injected As |
|-----------|-------------|
| `.css` | `<link rel="stylesheet" href="...">` in `<head>` |
| `.js` | `<script src="..."></script>` before `</body>` |

Multiple assets can be included:

```markdown
[INCLUDES]: # (H, F, /css/charts.css, /js/charts.js, /js/analytics.js)
```

## Asset File Placement

Put asset files in the `static/` directory. They are copied to the output as-is:

```
static/
  js/
    demo.js      → dist/js/demo.js
    charts.js    → dist/js/charts.js
  css/
    custom.css   → dist/css/custom.css
```

Then reference them with absolute paths in the INCLUDES directive.

> [!tip] Combining with Inline Scripts
> Asset includes and inline `<script>` blocks can coexist. Use asset includes for reusable code and inline scripts for page-specific behavior.
