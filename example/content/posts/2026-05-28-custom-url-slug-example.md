# Custom URL Slug Example

This post's filename is `2026-05-28-custom-url-slug-example.md`, but its URL is `/posts/custom-url.html` because of the directive:

```markdown
[SLUG]: # (custom-url)
```

Without the SLUG directive, the URL would be `/posts/custom-url-slug-example.html` (derived from the filename with the date prefix stripped).

## When to Use Custom Slugs

- Shorter, cleaner URLs: `[SLUG]: # (faq)` instead of `frequently-asked-questions`
- Renaming a file without breaking existing links
- SEO-friendly URL overrides

## URL Style Interaction

The SLUG directive works with both URL styles configured in `sitemaker.toml`:

| `urls.style` | SLUG value | Result |
|--------------|-----------|--------|
| `flat` | `custom-url` | `/posts/custom-url.html` |
| `directory` | `custom-url` | `/posts/custom-url/` |
