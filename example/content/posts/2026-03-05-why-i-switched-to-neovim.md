# Example: Why Someone Might Switch to Neovim in 2026

This example post illustrates an opinion piece format. Imagine a developer who was a VS Code user for five years, with the perfect setup — 47 extensions, a custom theme, keybindings tuned to muscle memory. Then a laptop died, and they realized they couldn't reproduce the setup.

That was the push they needed.

## The Breaking Point

Setting up VS Code on a new machine took **three hours**. Three hours of:

1. Installing extensions one by one
2. Syncing settings that didn't quite sync
3. Fixing conflicts between extensions
4. Remembering which settings had been changed manually

Meanwhile, a Neovim-using colleague cloned a dotfiles repo and was productive in 5 minutes.

## What Convinced Them

It wasn't the speed, though Neovim is absurdly fast. It wasn't the modal editing, though that grew on them. It was **reproducibility**.

An entire Neovim config can be ~200 lines of Lua in a single file[^1], living in a dotfiles repo. Setting up a new machine takes under a minute:

```bash
git clone https://github.com/example/dotfiles ~/.config
nvim --headless "+Lazy! sync" +qa
```

That's it. Done. Every plugin installed, every keybinding configured, LSP servers downloading in the background.

## A Minimal Setup

For the curious, here's a minimal plugin list:

```lua
require("lazy").setup({
    "neovim/nvim-lspconfig",
    "hrsh7th/nvim-cmp",
    "nvim-telescope/telescope.nvim",
    "nvim-treesitter/nvim-treesitter",
    "lewis6991/gitsigns.nvim",
    "folke/tokyonight.nvim",
    "echasnovski/mini.nvim",
})
```

Seven plugins. That's it. Compare that to 47 VS Code extensions.

## The Learning Curve

The first two weeks are typically painful. Everything is massively slower. But by week three, normal speed returns. By month two, many developers report being faster than they ever were in VS Code.

The key is **not trying to learn everything at once**. Start with just:

- `i` to enter insert mode
- `Esc` to leave it
- `:w` to save
- `:q` to quit
- `/` to search

Everything else comes gradually.

## Missing VS Code?

Sometimes. The debugger integration is better. The Git UI is nicer. And some extensions (like the REST client) have no good Neovim equivalent.

But the startup time, the Electron memory usage, and the three-hour setup ritual? Not missed by most who make the switch.
