# Sitemaker Examples

This is an example blog generated by Claude to demonstrate the features of **sitemaker**, a static site generator built with TypeScript, markdown-it, and Tailwind CSS v4.

## Example Posts

Check out the [example posts](/posts/) to see syntax highlighting, callouts, wikilinks, embedded HTML, inline JavaScript, and more.

## What This Demonstrates

All content on this site is example content written by Claude. It showcases:

- Obsidian-flavored markdown with wikilinks and callouts
- Syntax highlighting across multiple languages
- Embedded HTML and inline JavaScript in markdown
- External CSS includes (Pico CSS)
- Template overrides and custom footers
- Blog features: tags, dates, prev/next navigation, RSS
- Responsive design with Tailwind CSS v4
