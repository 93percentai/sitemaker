# About This Example Site

This is example content generated by Claude to demonstrate sitemaker's features.

## What Is This?

This site is a demo blog shipped with **sitemaker** to showcase its capabilities. All posts, pages, and templates are example content — not written from a real person's perspective.

## Features Demonstrated

- **Blog posts** with dates, tags, and reading time
- **Sidebar navigation** (visible on this page via the `SB` include)
- **Table of contents** generation from headings
- **Template overrides** including a custom footer and landing page
- **Multiple markdown features**: code blocks, callouts, wikilinks, footnotes, tables, task lists
- **External CSS/JS includes** via the INCLUDES directive

## Sitemaker

Sitemaker is a static site generator built with TypeScript. It uses:

- [markdown-it](https://github.com/markdown-it/markdown-it) for parsing
- [Nunjucks](https://mozilla.github.io/nunjucks/) for templates
- [Tailwind CSS v4](https://github.com/tailwindlabs/tailwindcss) for styling
- [highlight.js](https://highlightjs.org/) for syntax highlighting

## Source

The source for this example site is in the `example/` directory of the sitemaker repository.
