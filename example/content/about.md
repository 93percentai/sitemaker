# About Me

Hi, I'm **Dana Kim**. I'm a software engineer based in Portland, OR.

## What I Do

I work on distributed systems and infrastructure at a mid-sized tech company. My day-to-day involves:

- Designing and building high-throughput data pipelines
- Maintaining Kubernetes clusters and service mesh configurations
- Writing internal developer tools in Go and Rust
- Mentoring junior engineers

## This Blog

I started this blog to share things I've learned the hard way. Most posts fall into a few categories:

- **Deep Dives** — thorough explorations of specific technologies
- **War Stories** — post-mortems and lessons from production incidents
- **Tutorials** — step-by-step guides for tools and techniques I use
- **Opinions** — hot takes on industry trends (use at your own risk)

## Colophon

This site is built with **sitemaker**, a static site generator written in Go. It uses Obsidian-flavored markdown, Tailwind CSS, and deploys to Cloudflare Pages.

The source code is in a private repo, but the site generator is open source.
